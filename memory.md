- 2026-08-08 — **Three fixes from owner feedback on Phase 6.**
  1. **PDF exports were rendering Gujarati text as broken/missing glyphs — the actual bug behind "PDF export not working well."** jsPDF ships only Latin-only built-in fonts; any Gujarati text (entry-number labels, goods types, vepari names, everything really, since gu.json is used throughout) rendered as blank boxes without a properly embedded font. Fixed by embedding Noto Sans Gujarati directly into every generated PDF (`src/assets/notoSansGujaratiFont.js` — base64 TTF, ~240KB).
